# Nereus App Architecture and Current State (as of 25 March 2026)

## Overview
Nereus is a full-stack application for running, monitoring, and analyzing hydrodynamics simulations. It features a modern React frontend, a Django backend API, and a simulation worker, all orchestrated via Docker Compose. The system is designed for interactive 3D visualization, simulation management, and post-processing analysis.

## 2. Frontend Architecture (React)

- **Entry Point**: `frontend/src/App.tsx`
  - Uses React functional components and hooks.
  - State management via `useSimStore` (likely Zustand or similar).
  - Layout: Three main panels (Sidebar, 3D Viewport, Config/Analysis Panel).
  - Polling: Exponential backoff polling for simulation status.
  - Analysis: Loads post-run analysis data when simulation completes.
